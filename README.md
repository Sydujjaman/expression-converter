# Expression Converter & Evaluator

A simple C program that converts mathematical expressions between **Infix**, **Prefix**, and **Postfix** notations using binary trees.

## Features
- Convert expressions between Infix, Prefix, and Postfix
- Evaluate the result of the expression
- Built using binary tree data structure

## How to Run
1. Compile: `gcc Project.c -o expression`
2. Run: `./expression`

## Example
Input: `(3+5)*4`  
Output: `32`

## Limitations
- Supports only **single-digit numbers** (0–9)
- Only basic operators: `+`, `-`, `*`, `/`
- No error handling for invalid expressions
- Integer arithmetic only (no decimals)
- Maximum expression length is 100 characters
